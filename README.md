# RR Pressure Selector

An interactive analytics tool and dashboard for analyzing T20 / IPL player pressure ratings, batting and bowling metrics, and team planning for Rajasthan Royals (RR).

## Features
- **Comprehensive Pressure Ratings:** Ball-by-ball pressure index evaluations for batters and bowlers across IPL, T20I, or combined views.
- **Interactive Filtering & Sorting:** Filter by nationality, IPL team status, role, overs (powerplay/death), balls faced/bowled, and minimum qualification thresholds.
- **Squad & Target Planning:** Select and curate shortlists of batting finishers and bowling options.
- **Standalone Web App:** Self-contained dashboard with data views, dark/light theme support, and responsive table layouts.

## Getting Started

### Prerequisites
- Node.js (v18+)

### Running Locally
```bash
npm run dev
```
Or start the server directly:
```bash
node dev.js
```
The server will open at [http://localhost:5173](http://localhost:5173).

Alternatively, you can open `RR_Pressure_Selector.html` or `index.html` directly in any modern web browser.
